# deep-learning-60-days

# Deep Learning: 60 Days of Practical Learning

A hands-on journey from neural-network fundamentals to CNNs,
sequence models, attention and Transformers using Python,
NumPy and PyTorch.

## Objectives

- Understand neural networks and backpropagation.
- Implement and train models using PyTorch.
- Build and evaluate CNNs for image classification.
- Understand sequence models and Transformer attention.
- Develop reproducible, documented Deep Learning projects.
